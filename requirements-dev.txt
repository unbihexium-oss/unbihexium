# Abstract
# --------
# Exact versions of every dependency needed to develop, test, lint
# and release Unbihexium: the runtime dependencies plus the `all` extra
# (onnx, torch, serving, dask, ray, zarr, netcdf, stac, parquet and dev).
# GPU packages are excluded because they depend on the local CUDA
# installation; install them with `pip install ".[gpu]"`.
#
# Scope
#   One file covers CPython 3.10, 3.11, 3.12, 3.13 and 3.14 on Linux, macOS and
#   Windows. Environment markers select the newest release that supports each
#   interpreter and platform. PyTorch pulls in the NVIDIA CUDA runtime wheels on
#   Linux x86_64; they are large but do not require a GPU at install time.
#
# Usage
#   python -m pip install -r requirements-dev.txt
#   python -m pip install --no-deps -e .
#   pre-commit install
#
# Regeneration
#   Do not edit the uv output by hand. Change the version ranges in
#   pyproject.toml and regenerate the lock files with uv
#   (https://docs.astral.sh/uv/):
#
#       make lock
#
#   `make lock` (scripts/merge_lock.py) keeps this header, everything before
#   the line "# This file was autogenerated by uv", and the closing block at
#   the end of the file, and replaces the uv output in between.
#
# Verification (September 2026)
#   - Every pinned version publishes a wheel, or a pure Python source
#     distribution (asciitree), for CPython 3.10 to 3.14 on Linux
#     x86_64.
#   - pip-audit reports no known vulnerabilities for Python 3.10 and 3.14.
#
