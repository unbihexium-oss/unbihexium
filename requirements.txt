# Abstract
# --------
# Exact versions of every runtime dependency of Unbihexium, including the
# `onnx` (ONNX Runtime inference) and `serving` (FastAPI REST service)
# extras, for reproducible deployments. The container image built from the
# Dockerfile installs exactly these versions.
#
# Scope
#   One file covers CPython 3.10, 3.11, 3.12, 3.13 and 3.14 on Linux, macOS and
#   Windows. Environment markers such as `python_full_version < '3.11'` select
#   the newest release that supports each interpreter, because several
#   scientific packages no longer support Python 3.10 in their latest releases.
#
# Usage
#   python -m pip install -r requirements.txt
#   python -m pip install --no-deps .
#
#   The second command installs Unbihexium itself without resolving its
#   dependencies again, so the locked versions are kept.
#
# Regeneration
#   Do not edit the uv output by hand. Change the version ranges in
#   pyproject.toml and regenerate the lock files with uv
#   (https://docs.astral.sh/uv/):
#
#       make lock
#
#   `make lock` (scripts/merge_lock.py) keeps this header, everything before
#   the line "# This file was autogenerated by uv", and the closing block at
#   the end of the file, and replaces the uv output in between.
#
#   Dependabot proposes updates to the pinned versions weekly.
#
# Verification (September 2026)
#   - Every pinned version publishes a wheel, or a pure Python source
#     distribution, for CPython 3.10 to 3.14 on Linux x86_64.
#   - pip-audit reports no known vulnerabilities for Python 3.10 and 3.14.
#   - The test suite gives the same results as with the previous dependency
#     set on Python 3.10 and 3.14.
#
# The list below is generated by uv. Each entry shows which requirement pulled
# the package in ("via").
# =============================================================================
