Unbihexium {{ .Chart.AppVersion }} REST API: release {{ .Release.Name }} in namespace {{ .Release.Namespace }}.

Wait for the pods:
  kubectl --namespace {{ .Release.Namespace }} rollout status deployment/{{ include "unbihexium.fullname" . }}

{{- if .Values.ingress.enabled }}

The API is routed to:
{{- range .Values.ingress.hosts }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ . }}/health
{{- end }}
{{- else }}

Reach the API from this workstation:
  kubectl --namespace {{ .Release.Namespace }} port-forward service/{{ include "unbihexium.fullname" . }} 8000:{{ .Values.service.port }}
  curl http://127.0.0.1:8000/health
{{- end }}

Check the release:
  helm test {{ .Release.Name }} --namespace {{ .Release.Namespace }}

The models of the zoo are untrained starter models, except the spectral
index models; see the README of the project before relying on results.
