## Responsibilities

Maintainers:

- Review and merge pull requests according to [CONTRIBUTING.md](CONTRIBUTING.md) and the checks in `.github/workflows/`.
- Triage issues within the response times in [SUPPORT.md](SUPPORT.md).
- Handle vulnerability reports according to [SECURITY.md](SECURITY.md).
- Prepare releases according to [VERSIONING.md](VERSIONING.md) and keep [CHANGELOG.md](CHANGELOG.md) up to date.
- Keep the licensing, privacy and compliance documents accurate.

## Contact

Contact maintainers through GitHub issues. Report security vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/unbihexium-oss/unbihexium/security/advisories/new), never in a public issue.

## Code Owners

Review requests are assigned automatically through [.github/CODEOWNERS](.github/CODEOWNERS).
